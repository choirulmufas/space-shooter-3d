# Space Shooter 3D 🚀

Sebuah game 3D Space Shooter berbasis web yang dibangun menggunakan **Three.js**, **Tailwind CSS**, dan JavaScript modern.

## 🎮 Fitur Utama
- **3D Graphics & Visual Effects**: Asteroid belt, nebula galaksi, particle explosion, laser blaster.
- **Controls**: Keyboard/Mouse & Mobile Touch support (Virtual Joystick).
- **Audio & SFX**: Web Audio API synthesizer untuk sound effect futuristik dan dynamic sci-fi background music.
- **Upgrades & Score**: Sistem upgrade shield, weapon fire rate, dan high score persistent (localStorage).

## 🚀 Live Demo
Game ini dapat dimainkan langsung melalui browser tanpa instalasi tambahan.

## 🛠️ Cara Menjalankan Lokal
Cukup buka file `index.html` di browser modern apapun atau jalankan dengan local web server:
```bash
npx serve .
```
